# Flourishing Nature

A NeoForge mod for Minecraft 26.3 where animals herd, socialize, and flourish when they are
cared for.

## Building

Requires only a JDK able to run Gradle (17+). Gradle fetches Java 25 automatically.

```sh
./gradlew build                 # jar lands in neoforge/build/libs/
./gradlew :neoforge:runClient   # play in a dev client
```

See [docs/](docs/README.md) for setup, architecture, and contribution rules, and
[AGENTS.md](AGENTS.md) for the short version.
